# 🧮 Smart Calculator (Flask)

A modern smart calculator built using Flask with a clean UI.

## 🚀 Features

* Basic arithmetic operations
* Backend powered by Flask
* Responsive UI using HTML, CSS, JS
* Real-time calculations

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Flask (Python)

## ▶️ Run Locally

```bash
git clone https://github.com/balaraja18/Smart-Calculator.git
cd Smart-Calculator
pip install -r requirements.txt
python app.py
```

## 🌐 Output

Runs on: http://127.0.0.1:5000
